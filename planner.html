Battery type
Not sure what this means?

Lithium You can use almost all of it. Light, and lasts years longer.

AGM Cheaper to buy, but you can only use about half before it wears out. So it needs to be about twice the size, and it's three to four times heavier.

What kind of solar?
Not sure what this means?

Fixed roof panels Set and forget, and they charge while you drive. The van has to sit in the sun.

Portable blanket Park in the shade and lay it in the sun. It packs away, but you set it up each time.

One box or separate parts?
Not sure what this means?

All-in-one box Battery, chargers and plugs built in. The simplest option, and it can move between vehicles.

Separate parts More work and an installer, but you choose every piece and it can grow with you.
