How do you want it built?

Battery type

The short version: you can use almost all of a lithium battery, but only about half of an AGM before it starts wearing out. So AGM needs to be about twice the size for the same job, and it's around three to four times heavier. AGM is cheaper to buy; lithium lasts years longer.

What kind of solar?

Fixed panels: set and forget, and they charge while you drive, but the van has to sit in the sun. Blanket: park in the shade and lay it in the sun. It packs away, but you set it up each time.

One box or separate parts?

All-in-one box: battery, chargers and plugs built in. Simplest, and it can move between vehicles. Separate parts: more work and an installer, but you choose every piece and it can grow with you.
