# Off-Grid Sorted

Free Australian power planner for vans, caravans and 4WDs, plus plain-English guides.

Static site, no build step. Netlify publishes the repository root as is.

- `index.html`: the Power Planner
- `about.html`, `disclosure.html`, `privacy.html`
- `CLAUDE.md`: voice, safety and brand rules for anyone (or any AI) editing the site
