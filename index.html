Battery type

The short version: you can use almost all of a lithium battery, but only about half of an AGM before it starts wearing out. So AGM needs to be about twice the size for the same job, and it's around three times heavier. AGM is cheaper to buy; lithium lasts years longer.

One box or separate parts?

All-in-one box: battery, chargers and plugs built in. Simplest, and it can move between vehicles. Separate parts: more work and an installer, but you choose every piece and it can grow with you.
